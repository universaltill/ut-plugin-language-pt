## Hand check of meaning (all 68 keys)

Behaviour per `claim.md` / `move_approval.go`: manager or admin approves
or declines with a PIN; three wrong PINs decline; the till keeps selling;
nothing is wiped; sales history is merged into the other account. Every
Portuguese string carries that meaning: `mover`/`mudança` (never
`eliminar`/`apagar`/`transferir dados`), "Nada mudou" on every refusal and
result key where English has "Nothing changed", the warning states the
consequence and "O suporte nunca lhe pede para fazer isto".

Variety and register: European Portuguese as the manifest promises
(pt-PT): "a mostrar", "ecrã", "definições", "utilizadores",
"funcionários", "Ligue-se", "Contacte", "transferir" for download, no
"você"/"tela"/gerund. Terminology matches the neighbours: `caixa` for
till, `loja` for shop, `gerente` (35 uses) and `administrador`,
`proprietário` for owner, `associar` for pair (matches the existing
`settings.enrol.*` keys), `nuvem`, `suporte`. Agreement checked: "Movida
para %s" (a caixa), "Rejeitada." (a mudança). `%s` in `notice_pending` is
a shop name (`en.meta.json`), so "%s pediu para mover esta caixa para a
sua loja" is right.
